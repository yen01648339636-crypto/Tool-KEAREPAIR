KeaRepair Studio bundled font assets

Retrieved from the respective official project repositories on 2026-10-23.
The original font files are unmodified. All fonts are licensed under SIL OFL 1.1.
The CSS family names Kea Sans and Kea Mono are local stylesheet aliases.

Inter Variable: normal, variable weights 100-900, WOFF2.
JetBrains Mono Regular: normal, weight 400, WOFF2.
JetBrains Mono Medium: normal, weight 500, WOFF2.

For code, use font-variant-ligatures: none if literal operator shapes are preferred.
Chinese characters should use the platform CJK font fallback.
All requests are served locally; no external font host is needed at runtime.
